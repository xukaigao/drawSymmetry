# 🪞 画出对称的另一半

一个面向小朋友的网页益智游戏，帮助认识**轴对称**。在格子纸上给出一条**对称轴（镜子）**和图形的**一半**，
小朋友沿着格子把**另一半**画出来，画对即完成。图形由简单的**横线、竖线、斜线**组成。

🎮 在线试玩：`https://xukaigao.github.io/drawSymmetry/`

## 怎么玩

1. 红色虚线是**对称轴**，蓝色线是题目给出的**一半**图形。
2. 从一个**格点按住、拖到另一个格点松手**，画出一条直线：横、竖、45° 斜线，也可以是**跨 2~3 格的矩形对角线**（斜率 1/2、1/3、2/3、3、3/2 等）。拖动时有虚线预览；超过 3 格会变红、不会画上。
3. 把另一半画成和给定一半**关于对称轴镜像对称**的样子。
4. 画对的线变绿色，画到不对称位置的线变红色；当**不多不少、完全对称**时即通关 🎉。

操作：
- **撤销**：去掉最近画的一笔。
- **清空我画的**：只清掉自己画的，题目保留。
- **删除一条**：直接点那条线的中段。
- **提示**：短暂显示还没画的正确线段（金色虚线）。
- **换一题 / 对称轴 / 难度**：随时切换，竖直 / 水平 / 斜线轴，简单 / 中等 / 较难。

## 实现说明

- 图形 = 一组**基本格段**（端点为格点、且中间不经过其他格点的最小直线段，gcd=1）。
  - 45° 斜线、横线、竖线是基本格段；2~3 格矩形对角线（如 (2,1)、(3,1)、(3,2)）也是基本格段。
  - 任何「A→B 直线」在画上时会按 gcd 拆成若干基本格段，保证表示唯一、可与答案精确比对。
- 出题：在对称轴一侧随机走一条折线作为「一半」（难度越高，越会用到 2~3 格斜线），它关于轴的镜像就是标准答案。
- 判定：孩子画的基本格段集合 == 题目一半的镜像集合（用对称轴的反射变换计算），不多不少即通关。
- 支持竖直、水平、两种 45° 斜线对称轴；反射变换都把格点映射回格点，保证答案落在格子上。

难度：简单 = 只用横/竖/45°；中等 = 增加 2 格斜线；较难 = 再增加 3 格斜线。

## 技术栈

- 纯 **HTML + CSS + 原生 JavaScript**，无框架、无构建。
- **SVG** 绘制格子纸、对称轴、线段；用「指针坐标 → 最近格点」吸附实现顺滑的连点画线（Pointer Events，支持触屏）。

## 文件结构

```
drawSymmetry/
├── index.html      # 页面结构 + 控制面板
├── css/style.css   # 格子纸主题、响应式
└── js/game.js      # 出题、画线交互、镜像判定
```

## 本地运行

直接用浏览器打开 `index.html` 即可，或起本地静态服务器：

```bash
python -m http.server 8000   # 然后访问 http://localhost:8000
```

## 部署为 GitHub Pages

推到 `xukaigao/drawSymmetry` 仓库后，在 **Settings → Pages** 选 `Deploy from a branch`，
分支 `main`、目录 `/ (root)`，保存。约 1~2 分钟后访问 `https://xukaigao.github.io/drawSymmetry/`。
（免费版需要仓库为 public。）随后把它加进游戏厅首页 `xukaigao.github.io` 的 `GAMES` 数组即可。
